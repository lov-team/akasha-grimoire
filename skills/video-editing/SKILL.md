# 通用视频剪辑

先形成编辑决策，再渲染；不要在不可追溯的一长串临时命令中完成成片。

## 建立编辑工程

读取脚本、镜头表、来源清单、转写、字幕和已有 EDL。探测每个采用文件的时长、流、帧率、分辨率和音频；文件异常先退回素材阶段。

按 [references/editing-decisions.md](references/editing-decisions.md) 建立粗剪，输出符合 [references/edl-schema.md](references/edl-schema.md) 的 `edl.json`。每个 clip 必须引用 `clip_id`、`shot_id`、源文件和源入/出点。

## 决策顺序

1. 先锁定叙事骨架和 A-roll/旁白节奏。
2. 删除重复、停顿、无信息动作和未兑现铺垫。
3. 在证据、动作变化、情绪反应和视觉疲劳点加入 B-roll；不要平均撒镜头。
4. 用动作匹配、视线、声音桥、构图或色彩建立转场；特效只服务意义。
5. 声音先保证对白清晰，再加入环境、音效和音乐。
6. 字幕按实际声音时间码制作，检查断句、屏幕安全区和镜头切换。
7. 最后统一颜色、响度、输出编码和多平台画幅。

## 确定性渲染

执行脚本前将本 Skill 目录解析为绝对路径并记作 `editing_skill_dir`。

先检查命令而不渲染：

```bash
python3 "$editing_skill_dir/scripts/render_edl.py" /ABSOLUTE/PROJECT/edl.json \
  --output /ABSOLUTE/PROJECT/render/rough-cut.mp4 --dry-run
```

确认后去掉 `--dry-run`。脚本支持视频片段裁切、统一分辨率/帧率、缺失音轨补静音、顺序拼接和 H.264/AAC 导出；复杂叠加、字幕与混音按参考命令分层完成，不把它们塞进不可审阅的 EDL 字段。

基础 EDL 只接受视频流。静态图片先按实际需要的镜头时长转为中间视频；代理、字幕烧录、旁白/音乐混音和响度归一化命令见 [references/ffmpeg-recipes.md](references/ffmpeg-recipes.md)。

## 精剪与声音

- 裁切需要帧精度时重编码；只在允许关键帧误差时使用 stream copy。
- 音频转场优先 J/L cut 和环境声桥，视觉转场不自动切断声音。
- 对白轨先清理再测响度；默认以固定电平混合音乐，不根据旁白出现与否自动降低背景音乐。只有合同明确要求且试听无抽吸感时才启用轻微 ducking。
- 旁白同时作为侧链信号和主混音输入时必须用 `asplit` 建立两个显式分支；渲染日志中不得出现静音粗剪轨被自动接入 `amix` 代替旁白。
- 合同要求音乐时必须采用可辨识旋律、和声或节奏结构的音乐素材；白噪声、雨声、风声和程序化噪声只登记为 SFX/ambience。
- 最终混音至少验证：旁白 stem 可转写、音乐 stem 非静音、成片混音仍可转写出主要旁白；同时记录对白、音乐和总混音响度。
- 固定电平混音的最终母带不得使用动态响度归一化改变段落增益；优先采用受 true peak 上限约束的固定总增益。
- 保留 handle，避免生成片段刚起步或刚结束的失真帧直接入成片。
- 所有代理、预览和最终输出使用不同文件名，拒绝覆盖源素材。

## 交付 QA

渲染后 **REQUIRED SUB-SKILL:** 使用 `$video-qc`。技术通过后仍需完整播放；问题必须回写到 `clip_id`/`shot_id` 和时间码，再重渲染受影响版本。交付 `edl.json`、渲染命令、字幕、独立声音文件、最终成片和 QA 报告。
