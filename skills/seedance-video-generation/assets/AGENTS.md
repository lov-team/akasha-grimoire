# AGENTS.md

## Seedance 视频生成

- Seedance / 豆包文生视频、图生视频或带参考素材的视频生成必须使用 `seedance-video-generation` Skill。执行前完整读取当前会话暴露的 `SKILL.md` 及其要求的资源，优先使用 Skill 自带脚本，不凭记忆拼装请求。
- 用户明确指定模型时使用该模型；未指定时使用 Skill 默认模型。模型能力、时长和素材限制以当前 `SKILL.md` 与脚本校验为准，不在项目规则中复制易过期的参数表。
- 真实生成会计费。只有用户明确要求生成或确认计费后才能提交任务；先执行一个 5 秒、720p 的最小代表任务，验证模型、端点、输入类型、输出格式和下载链路，再扩大时长、画质或批量数量。
- 参考图片、视频和音频必须是上游可直接访问、无需客户端鉴权的公共 HTTPS URL。不得把本地路径、内网地址、临时登录态 URL 或含凭证的 URL 发送给上游。
- 每轮输出写入唯一的仓库外目录 `/tmp/<project>-seedance-<task>-<round>/`。原始响应、中间文件、代表帧和淘汰稿不得直接进入仓库；未获明确指令不得覆盖已有文件。
- HTTP 2xx、任务 `SUCCESS`、异步任务 `completed` 或脚本 `OK` 只证明调用完成，不代表成片合格。必须验证最终文件非空且为 MP4，用 `ffprobe` 核对时长、编码和分辨率，并抽取开头、中间、结尾代表帧检查主体一致性、运动连续性、镜头、文字、水印和提示词约束。
- 只有成片通过验收后，才能复制到项目生产目录。交付时记录实际 Skill、脚本、模型、生成次数、时长、分辨率、输出路径、验收结果和未验证项；不要记录完整 provider 响应、base64、临时媒体 URL 或凭证。
- 凭证只从 Skill 规定的环境变量或受控凭证存储读取，不得写入 prompt、命令参数、日志、文件名、元数据、仓库或交付说明。Skill 不存在、脚本缺失、provider 能力不一致或无法真实调用时，明确报告阻塞和替代验证方式，不得临时手写含凭证的 `curl` 绕过 Skill。
