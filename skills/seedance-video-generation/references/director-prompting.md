## 1. 选择提示词模式

按镜头复杂度选择，而不是给所有请求套同一份长模板：

- **单镜头**：4–6 秒、一个主体、一个主要动作。写起始构图 → 动作 → 相机反应 → 结束构图，不强拆时间段。
- **时间轴多镜头**：7–15 秒、两个以上叙事节拍、需要切镜或卡点。使用 [`../assets/director-prompt-template.txt`](../assets/director-prompt-template.txt)。广告、产品、音乐卡点优先用它。
- **电影叙事序列**：写实或动画剧情、多角色、多场景，每 3 秒一段、整段 15 秒一次生成，长片由多个 15 秒单元剪成。使用第 8 节的导演稿与 [`../assets/cinematic-sequence-template.txt`](../assets/cinematic-sequence-template.txt)。
- **运镜/动作复刻**：带 `--reference-video`。参考视频负责镜头轨迹、动作节奏或转场中的一种或几种，人物、产品、场景由图片与文本分别锁定。
- **首尾帧控制**：用 `--first-frame` / `--last-frame` 锁定真实边界；提示词只描述两帧之间可完成的运动过程。
- **尾帧续拍**：改用相邻的 `$seedance-video-continuation`，不要只写“保持一致”冒充真实尾帧续接。

## 2. 建立成片合同

写 Prompt 前锁定：

- 时长、画幅、写实/动画媒介和整体节奏。
- 主体、场景、唯一主要事件与最终落点。
- 不可变项：身份、服装、产品几何、道具数量、主光方向、屏幕运动方向。
- 声音策略：原生声音、参考音频、环境声、对白、配乐与关键卡点。
- 需要避免的少量高损失错误。不要堆叠泛化否定词。

把“高级、电影感、炸裂”翻译成可观察行为：具体景别、机位、光型、动作、对焦、速度和声音。

## 3. 绑定参考素材职责

new-api CLI 已把参考素材写入结构化角色：`first_frame`、`last_frame`、`reference_image`、`reference_video`、`reference_audio`。

多张参考图时按序号指代，序号是该图在请求 `content` 中图片项的顺序（脚本依次写入 `--first-frame`、`--last-frame`、`--reference-image`，同类按命令行出现顺序）。2026-10 实测：`seedance2` 能按「@图 N」把 4 张参考图分别对上角色和场景（第 8 节的模板就是这样写的）。序号后最好仍带一句可见描述，或在「场景环境」里写清场景内容，上游没有解析序号时描述本身仍能绑定。视频、音频同理写「@视频 1」「@音频 1」。

职责示例：

```text
首帧严格锁定人物身份、服装、初始构图和主光方向。
参考图片只负责产品外形、材质和标签位置。
参考视频只负责运镜轨迹、动作节奏与遮挡转场，不沿用其中的人物和场景。
参考音频负责节拍和高潮位置；动作音效仍按画面事件生成。
```

多份素材都含有人物或场景时，明确主次和冲突优先级。重复素材不会自动提升一致性。

## 4. 编排秒级时间轴

时间轴必须从 `0.00` 开始、连续无重叠，并精确覆盖命令的 `--duration`：

```text
0.00–1.50秒：建立主体或前三秒钩子。
1.50–4.00秒：执行第一个主要动作。
4.00–7.50秒：通过明确触发物转场并展示核心变化。
7.50–10.00秒：完成动作、情绪或产品英雄定格。
```

编排规则：

1. 每段只承担一个主要视觉任务和一个主要动作。
2. 普通动作至少预留约 1.5–2 秒；复杂动作预留约 2–4 秒。信息放不下就删镜头，不压缩成动作清单。
3. 快节奏通过短镜头、明确卡点和干净切换实现，不靠相机持续乱动。
4. 只有切镜能增加主体、空间、状态、视点或时间信息时才切镜；只改变距离或小角度时使用连续运镜。
5. 一镜到底不使用“切到”“硬切”等语言，依靠跟随、遮挡、甩动、材质匹配和空间贯通。
6. 前三秒先给异常、冲突、信息缺口、治愈动作或视觉奇观中的一个，不先解释背景。

## 5. 写可执行的摄影语言

每个镜头按以下顺序写：

```text
景别与机位 + 主体单一动作 + 运镜类型/幅度/速度 + 对焦目标 + 光线变化 + 同步声音 + 结束构图
```

完整运镜包含：

- **类型**：推、拉、摇、移、升降、跟拍、环绕、固定、轻微手持。
- **幅度**：小幅、中幅、大幅，或明确环绕角度。
- **速度**：慢速、正常、快速；速度变化要写触发点。
- **目标**：推进到谁、揭示什么、保持谁在画面哪个位置。

示例：

```text
中景眼平机位，人物从画面右侧向左奔跑；摄影机等速侧跟，小幅度、正常速度，焦点锁定眼睛，人物始终位于右侧三分线。
```

避免在同一时间段同时要求固定机位、快速推进、360° 环绕和强手持。确需组合运镜时写清先后触发条件。

常用情绪映射：

| 目的 | 优先摄影行为 |
|---|---|
| 克制、靠近情绪 | 小幅慢推、浅景深、近景 |
| 孤独、揭示环境 | 缓慢拉远、升高、远景 |
| 代入动作 | 后跟或侧跟，保持屏幕方向 |
| 主角强化 | 有限角度环绕，不无目的旋转 |
| 心理冲击 | 快推或希区柯克变焦，只用于关键点 |
| 紧张与真实 | 轻微手持、对焦延迟、呼吸与前摇 |

## 6. 设计声音与转场

按层写声音：

- 环境声维持空间真实性。
- 动作音效必须由画面中的具体动作触发。
- 对白写说话人、发声方式、原文和开始时间，给口型留足时间。
- 配乐写乐器、速度、进入点、高潮点和收尾，不只写“电影级音乐”。

转场写触发物和发生时刻：前景遮挡最满时切换、甩镜运动模糊中切换、闪光峰值切换、动作姿态匹配切换。不要只写“丝滑转场”。

## 7. 生成前审查

提交前逐项检查：

- 时间轴与 `--duration` 完全一致，无空档、重叠或越界。
- 每段只有一个主要动作，动作能在分配时长内完成。
- 运镜包含类型、必要的幅度/速度和明确目标，没有相互冲突。
- 素材职责唯一且主次明确；CLI Prompt 未混入网页端 `@素材` 标记；「图片N」序号与命令行传入顺序一致，且每个序号都带可见描述。
- 人物、产品、服装、场景方向、光线和不可逆状态在镜头间可追踪。
- 声音事件与画面事件对齐；转场有触发物和切换时机。
- 只保留高概率、高损失的限制，不让否定词淹没主要事件。

完整片超过 5 秒时，先另写一个只覆盖前 5 秒的 smoke Prompt；不要把 15 秒时间轴配 `--duration 5` 提交。smoke 通过后再使用完整 Prompt 扩大生成。

## 8. 电影叙事序列：导演稿模板与一口气 15 秒流程

多角色、多场景的剧情片段，按这一节写成「导演稿」，整段 15 秒一次生成。格式照搬 [`../assets/cinematic-sequence-template.txt`](../assets/cinematic-sequence-template.txt)，完整范例见 [`../assets/examples/winter-ball-15s.txt`](../assets/examples/winter-ball-15s.txt)（约 8200 字，五段，2026-10 用 `seedance2` 一次生成五段顺序全部正确）。

### 8.1 流程

1. **角色三视图**：每个主角一张正面、侧面、背面全身三视图，纯色背景，服装完整，交付画幅。用 `$gpt-image-generation` 生成，或直接用用户提供的三视图。
2. **场景图**：每个场景一张空景参考图，画内光源、材质和纵深要和导演稿一致。
3. **上传与核验**：参考图上传到公共 HTTPS，重新匿名下载核对 SHA-256 与 MIME（临时托管会过期，生成前确认链接仍有效）。
4. **写导演稿**：按 8.2 的格式写满 15 秒，交用户审阅后再提交。
5. **一口气生成**：整份导演稿一次提交 `--duration 15`，参考图按 @图 1…N 的顺序传 `--reference-image`。不要拆成多个短请求再拼。
6. **抽帧验收**：用画面差异找出实际切点，和时间段对比；按每段中点抽帧做联系表，逐段核对场景、景别、动作节拍、视线、揭示时机和角色是否像参考图；台词用音量包络确认出现时间。
7. **只改一处再生成**：每轮只改导演稿里出问题的那一段或那一个字段，保留其余文字不动，便于对比。

### 8.2 导演稿格式

导演稿是纯文本，不加 Markdown 标题、粗体、注释或「第几秒」标签，严格按以下顺序：

1. `镜头 N`
2. 风格段：全片一段，逐字复制到每一份导演稿。写媒介与质感、胶片颗粒、二分光影与轮廓光、大光圈大光比、景深纵深、在合适的镜头里适当加入丁达尔光、环境雾、浮尘、镜头炫光，以及「不要出现字幕，不要配音乐，只出现角色声音和环境音效」。
3. 角色绑定行：每个主角一行「【称呼】形象参考@图 N。」称呼全片固定。场景不在这里绑定。
4. 时间段：`0.0-3.0 秒`、`3.0-6.0 秒`……连续覆盖到 15 秒。每段固定四个字段，各占一行：
   - **场景环境**：「参考@图 N 的【场景】」开头；空间结构与材质；背景人物持续在做的两三件事；画内光源及其位置；声音分三层（近、中、远）；空气介质。回到同一场景写「切回参考@图 N 的……」。
   - **镜头设计**：起幅构图（前景、中景、后景与主体位置）→ 前景穿越或焦点转移 → 一个连续运镜（幅度、速度、目标）→ 落幅构图；焦距 + 摄影机距离 + 透视结果；焦点从哪里拉到哪里。
   - **可见动作**：一整段连续文字，不拆成秒。写 8–10 个微动作与表情节拍：小习惯、下意识动作、服装与道具的物理反应、被外界打断后的反应、想压住却漏出来的表情、落幅状态。视线写成「落在镜头左侧／右侧边缘之外、朝画外的……」。台词写「用【语气】说：「原文。」」。
   - **光影布光**：画内光源与方向；半张脸受光、半张脸进阴影；轮廓光位置；道具高光；背景散景颜色；浮尘、丁达尔光或炫光；胶片颗粒。
5. 最后一段的镜头设计以「落幅停稳」收尾，留给剪辑。

### 8.3 密度与节奏

- 每 3 秒一段、每段约 1500 字是验证过的密度：五段 15 秒约 7500–8500 字，`seedance2` 仍按顺序给出五段。
- 每段都要有动感：一个有起幅和落幅的连续运镜，加上前景穿越、背景人群流动或焦点转移中的至少一种。
- 揭示类节拍（人群安静 → 他怔住 → 她出现）在前面的段落里写明「楼梯顶端空无一人」，否则模型会提前让被揭示的人出现。

### 8.4 焦距语法：焦距 + 机距 + 结果

只写「85mm」模型学不到你要的画面。要把焦距、摄影机距离和画面结果写成一句因果：

| 焦距 | 摄影机距离 | 写出的画面结果 | 典型用途 |
|---|---|---|---|
| 24mm 广角 | 贴近主体或台阶中轴 | 近大远小强烈，线条向纵深汇聚，空间有压迫感 | 全景、对称构图、人物步入宏大空间 |
| 35mm 小广角 | 贴近两人侧后方或前景遮挡物 | 近大远小，纵深强，人物与环境同在 | 过肩、框架构图、手持环绕、带环境的中景 |
| 50mm 标准 | 社交距离 | 透视自然，接近人眼 | 平实的对话与交代 |
| 85mm 中长焦 | 拉开距离 | 背景相对放大并贴近人物，前后空间被压缩，浅景深，焦点锁住眉眼 | 胸像近景、情绪反应、双人近景 |

### 8.5 光与视线

- 每一束光都来自画内看得见的光源，如「火把暖橙光自画左斜铺」，同一场景里主光方向跨段不变。要二分光时写明「近处唯一光源」。
- 正反打时，人物看着的东西在他对面，他身后是另一侧的空间：人物在看楼梯，背景写身后的大厅与人群，不写楼梯。
- 被看的一方用相反方向的视线或运动接上：他看向画左上方，她就从楼梯上朝画右下方走来。

### 8.6 已知限制（2026-10 实测）

- **版权**：成片形象接近知名 IP（例如某魔法学院的标志性造型、学院配色与旗帜）时，`seedance2` 会在生成后拒绝：`output video may be related to copyright restrictions`。Prompt 里没有 IP 名称也会触发；不要为了绕过检测而改写措辞，改成真正原创的造型、配色和道具。
- **真人面孔**：用真人三视图作参考时，Seedance 只保留服装，面孔会漂移成别人。需要真人面孔一致的镜头，先用首帧锁脸或改用专门的口型/真人工具，并在交付前逐镜确认像本人；使用真人肖像前确认已获授权。
- **角色漂移**：发色、眼镜款式等细节会偏离三视图；把这些特征写进可见动作和光影布光里反复出现，比只靠参考图更稳。
- **色调**：场景图偏冷时成片会偏冷蓝；风格段写的暖调需要场景图本身也是暖调。
