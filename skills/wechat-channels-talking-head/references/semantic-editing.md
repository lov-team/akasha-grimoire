# 语义保真剪辑规则

## 语义单元

把逐字稿拆成承担单一功能的单元，而不是机械按句号切分：

- `claim`：核心判断或阶段结论；
- `definition`：解释术语和讨论范围；
- `bridge`：连接两个概念、领域或因果阶段；
- `evidence`：事实、引用、例证或演示；
- `qualification`：条件、限度、例外和不确定性；
- `contrast`：反方、误解、转折和修正；
- `emotion`：影响人物可信度与观看关系的停顿、笑声和语气；
- `filler`：不承载上述功能的语气词或废弃口误。

只有确认属于 `filler` 的完整区间才可自动列为 `safe_cut`。

## 删除测试

对每个候选删除区间回答：

1. 删除后，后一句中的“所以、但是、这个、它、也就是说”仍有明确指代吗？
2. 删除后，结论仍由前文推出，而不是突然出现吗？
3. 删除后，类比是否还保留“相似在哪里、不相同在哪里”的边界？
4. 删除后，讲话者的限定是否还在，观点是否被夸大？
5. 删除后，情绪、呼吸和表情是否仍自然？

任一答案为否，标为 `must_keep` 或扩大保留区间。

## 跨域观点的特殊保护

数学、哲学、经典文本、科学与 AI 等跨域口播常依赖多层桥梁。至少保留：

1. 每个领域在当前口播中的工作定义；
2. 从 A 到 B 的共同结构，不只保留“它们有关”这句结论；
3. 类比边界，避免把思想启发说成科学证明；
4. 从历史思想到现代技术的中间机制；
5. 讲话者最终希望观众理解的独特判断。

剪掉例子前先判断它是否是唯一能让抽象桥梁被理解的证据。

## 节奏规则

- 句内思考停顿通常保留；明显卡壳可缩短但不压成机器节奏。
- 句间保留约 120—300ms 自然余量，具体以语气和画面动作决定。
- 切点避开爆破音、擦音、吸气中段、手势起落中段和眨眼异常帧。
- 相邻保留段音色或环境噪声突变时，用 room tone、短交叉淡化或 J/L cut 修复。
- 连续三次以上同景别跳切时，优先调整构图或增加有意义的覆盖画面。

## 返工方法

用户指出具体意思缺失时：

1. 在逐字稿中定位缺失命题及其前后桥梁；
2. 从原片恢复最小完整语义区间，而不是只补一个孤立句子；
3. 更新 `cut-plan.csv` 的状态和理由；
4. 只重渲染受影响片段或版本；
5. 对比播放修复前后版本，确认新增内容确实恢复论证。
