# 视频号封面与发布文案

## 封面简报

先写 `cover-brief.md`：

- 成片核心命题与观众收益；
- 主体照片或采用帧；
- 用户参考图体现的构图、色彩、字重、光线和质感；
- 主标题、辅助句和栏目标签；
- 主体保留区、文字区、禁止裁切区；
- 不得出现的误导元素。

参考风格只抽取视觉语言，不复制参考图中的人物身份、Logo、水印或原文案。

## 标题结构

先写 5 个差异化候选：

1. **关系型**：`数学、道德经与AI，原来在谈同一件事？`
2. **反差型**：`AI越先进，为什么越像古老智慧？`
3. **收益型**：`理解AI之前，先理解“规律”`
4. **问题型**：`道德经真的能解释AI吗？`
5. **判断型**：`AI不是魔法，而是对规律的逼近`

选择时检查：具体、可读、有冲突、成片兑现。封面主标题优先 8—16 个汉字，可拆成 2—3 行；发布标题可更完整，但不要堆满标点和标签。

## 视觉层级

- 3:4 母版使用 1080×1440；主体脸部和主标题同时落在中心安全区域。
- 主标题是第一层，人物是第二层，辅助句和栏目标签是第三层。
- 同一画面最多两种字体、三种主要颜色；主标题与背景保持强对比。
- 生成模型只负责人物之外的概念背景或整体无字底图；中文文本由 `render_cover.py` 渲染。主标题可用 `|` 指定语义完整的换行位置。
- 缩小到手机列表尺寸检查，主标题应在一秒内读完。

## 简介模板

```markdown
# 发布文案

## 采用标题


## 简介

用 60—120 个汉字完成：提出问题 → 说明这条视频连接了哪些概念 → 给出观看收益。不要直接复述封面标题。

## 话题

#人工智能 #认知 #哲学

## 备选标题

1.
2.
3.
4.
```

话题保留 3—5 个，优先内容分类和核心概念，不使用与视频无关的热点词。
