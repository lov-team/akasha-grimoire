## 1. 适配原则

H3 沿用 Seedance 的导演级表达顺序：**成片合同 → 素材职责 → 连续性 → 秒级动作与摄影机 → 结束构图 → 声音 → 输出限制**。这是一套镜头描述方法，不代表 H3 支持 Seedance 的全部素材类型或请求字段。

- H3 文生视频使用 `minimax-h3/text-to-video`，Prompt 同时承担静态世界与动态镜头合同。
- H3 图生视频使用 `minimax-h3/image-to-video`，首帧已经承担身份、服装、景别、构图、场景和光线；Prompt 重点描述允许变化、摄影机、时间过程和结束状态。
- 一张参考图是首帧；第二张是尾帧。H3 不接收 Seedance 的参考视频、参考音频或任意多图职责。
- 请求参数负责模型、时长、分辨率与素材 URL；Prompt 不伪造 API 字段，也不写网页端 `@素材` 标记。

## 2. 选择提示词模式

- **4–6 秒单镜头**：一个主体、一个主要事件。使用紧凑三段式微时间轴：起幅／建立 → 主要变化 → 落幅／保持。
- **7–15 秒单镜头**：需要清楚的多节拍人物动作或连续运镜时，使用完整秒级时间轴。
- **首尾帧控制**：Prompt 只描述两帧之间可完成的连续过程；首尾景别、空间或人物状态差异过大时拆成独立镜头。
- **A/B 实验**：先写共享 Prompt，再改变唯一请求字段或首帧，不分别自由改写两份 Prompt。

## 3. 建立成片合同

写 Prompt 前明确：

- 时长、媒介与质感、整体节奏；
- 唯一核心事件，以及观众需要读到的变化；
- 起始可见状态与最终可见状态；
- 摄影机是固定还是运动，运动的动机、类型、幅度、速度和目标；
- 不可变项与唯一允许变化；
- 声音是模型生成、参考氛围，还是交给后期。

把“电影感、紧张、高级”改写为可观察行为，例如“眼平近景、摄影机锁定、视线在 1.20 秒后缓慢抬起、最后 0.80 秒形成克制微笑并保持”。

## 4. 绑定 H3 参考帧职责

图生视频 Prompt 必须明确：

```text
首帧严格锁定人物身份、服装、现有景别与取景范围、初始姿态、道具关系、场景空间和主光方向。
只允许<唯一变化>发生；不得重新构图或发明首帧外的新主体。
```

传入尾帧时补充：

```text
尾帧锁定最终姿态、道具位置与结束构图；中间运动连续到达尾帧，不切镜、不瞬变。
```

没有真实尾帧时不写“尾帧锁定”。不要把自然语言中的“最终画面”误写成已提供尾帧。

## 5. 编排秒级动作与摄影机

时间段从 `0.00` 开始，连续、无重叠并精确覆盖请求时长。每段只安排一个主要动作；一个短镜头只保留一个核心事件。

每段按以下顺序写：

```text
时间范围：现有景别与机位 + 主体单一动作 + 摄影机类型/幅度/速度/目标 + 焦点 + 同步声音 + 结束构图
```

摄影机字段：

- **类型**：固定、推、拉、摇、移、升降、跟拍、有限角度环绕；
- **幅度**：零、小幅、中幅、大幅或明确角度；
- **速度**：静止、慢速、正常、快速，必要时写触发点；
- **目标**：保持谁在画面哪里、推进到什么景别、揭示什么；
- **焦点**：锁定眼睛、道具或动作接触点，避免无理由漂移。

固定镜头也要写完整：`摄影机固定，幅度为零、速度为零，严格保持首帧景别、机位、取景范围和主体位置。`

4 秒单镜头示例：

```text
0.00–1.20秒：保持首帧起幅；人物低头凝视手中道具，只有自然呼吸。摄影机固定，幅度为零、速度为零，焦点锁定眼睛与道具。
1.20–3.20秒：人物缓慢抬起视线，头部、躯干、手和道具保持不动；摄影机仍固定，不重新构图。
3.20–4.00秒：人物形成克制的自信微笑并保持；结束构图与首帧完全相同，只改变视线和嘴角。
```

## 6. 声音与连续性

声音按层选择，不写空泛的“电影级音效”：

- 环境声：地点、距离和持续方式；
- 动作音：必须由可见动作触发；
- 对白：人物、原文、语气和发生时间；
- 配乐：乐器、速度、进入点、高潮与结束；
- 后期声音：若后期制作，Prompt 写“无对白、无配乐，仅保留克制环境底噪”，生成后移除模型音轨。

连续性只冻结高价值字段：身份、发型、服装、手指与握持关系、关键道具文字/数量/状态、场景锚点、主光方向、屏幕方向和既有景别。明确唯一允许变化，优先写正向保持要求，再列少量高概率高损失错误。

## 7. A/B 实验纪律

单变量实验必须建立共享基线：

1. 同一模型、时长、分辨率、动作时间轴、摄影机、声音和连续性约束；
2. 只改变被研究的字段，例如首帧景别；
3. 若变量已由首帧表达，共享 Prompt 写“保持首帧既有景别”，两份 Prompt 逐字相同；
4. 不在 A 写“中近景”、B 写“近景”，否则图像差异与文字差异同时存在；
5. 记录请求差异并在提交前做结构化比较。

## 8. 生成前审查

- `duration` 与时间轴精确一致，无空档、重叠或越界；
- 核心事件只有一个，各动作能在分配时间内完成；
- 参考帧职责与真实传入素材一致；
- 摄影机包含类型、幅度、速度和目标，没有“固定同时推进”等冲突；
- 起始状态、动作触发、最终状态和结束构图可见、可验收；
- 唯一允许变化与冻结项没有冲突；
- 声音策略明确，后期项目不会误把模型音轨当正式声音；
- A/B 共享字段逐字一致，只有实验变量不同；
- 限制项只覆盖高概率、高损失错误。
