# 外部方法参考

这些项目只作为方法与能力路由参考。使用前核对当前版本、入口、模型后端和许可证；不复制其代码、模板或大段说明。

- [Humanizer-zh](https://github.com/op7418/Humanizer-zh)：中文终稿自然化，不承担事实研究。
- [dbskill](https://github.com/dontbesilent2025/dbskill)：选题、Hook、商业表达和标题诊断。
- [content-research-writer](https://github.com/openakita/openakita/tree/main/skills/content-research-writer)：来源研究、提纲、初稿和引用流程。
- [notebooklm-skill](https://github.com/claude-world/notebooklm-skill)：资料库式研究方法参考。
- [khazix-skills](https://github.com/KKKKhazix/khazix-skills)：深度研究和热点分析方法，不复制个人文风。
- [ian-xiaohei-illustrations](https://github.com/helloianneo/ian-xiaohei-illustrations)：把观点、流程和隐喻转成手绘插图。
- [guizang-social-card-skill](https://github.com/op7418/guizang-social-card-skill)：3:4 社交卡片排版参考。
- [baoyu-skills](https://github.com/JimLiu/baoyu-skills)：封面、信息图和插图补充路线。
- [guizang-ppt-skill](https://github.com/op7418/guizang-ppt-skill)：后续演示文稿分发。
- [html-anything](https://github.com/clockless-org/html-anything)：HTML 展示方法；文字卡片优先使用当前项目内可控 HTML/CSS。

默认方法链：选题诊断 → 来源研究 → 写作 → 中文自然化 → HTML/CSS 或已确认视觉路线 → QA。
