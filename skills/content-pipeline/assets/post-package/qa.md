# QA

## Sources and copy

- [ ] 关键事实可追溯，当前事实已复核
- [ ] 事实、引用、观点和推断已区分
- [ ] 图片及外部素材已记录来源和使用边界
- [ ] 内容地图中的核心判断、论据、例子和结论都有去向
- [ ] 轻编辑没有改变原意、判断强度或个人经历性质
- [ ] 标题、封面和正文承诺一致
- [ ] 已清理空话、机械排比和模板化表达
- [ ] 无编造数据、经历、案例、引用或结果

## Delivery contract

- [ ] `brief.md` 已冻结内容类型、图片数量与职责、配文、标签、CTA 和平台边界
- [ ] 用户最新修正已同步到文案和卡片计划
- [ ] 图片与配文承担各自职责，没有错放教程、边界说明或核心信息
- [ ] 标签与 CTA 符合合同；不需要时已记录“无”

## Cards

- [ ] 尺寸和格式符合冻结合同
- [ ] 每页一个核心意思且信息足够
- [ ] 正文无错字、乱码、遮挡、溢出和错误裁切
- [ ] 成图文字已与锁定文案逐字核对；需要时已完成 OCR 辅助检查
- [ ] 新视觉路线有 3—5 个真实参考来源并经用户确认
- [ ] 模板 ID、状态、当前来源、实测尺寸和适配性复核已写入 brief
- [ ] 文字型帖子优先使用 HTML/CSS；图片调用符合视觉合同
- [ ] 封面已检查标题层级、断行、边距和手机可读性
- [ ] 一张高密度正文样卡已在批量生成前确认
- [ ] 已查看网格预览、手机预览和每张原图
- [ ] 同一帖子视觉系统一致

## Package

- [ ] 必需文件齐全，manifest 状态真实
- [ ] 原始输入、采用文件和最终输出清单足以支持中断后继续
- [ ] 卡片数量、顺序和职责与计划一致
- [ ] 临时文件、接口响应和淘汰稿未混入正式内容包
- [ ] 内容包不含密钥、Cookie、未经允许复制的私人来源或未获许可素材
