# 专项资产

## 角色一致性

先建立身份卡：头身比、脸型、发型、服装分层、调色板、标志物、左右不对称、持物手与比例。多视图把身体左右转换为观察者方向逐项核对；侧视必须是真正 profile。每次编辑列 freeze-list，只改变当前目标。手与道具的接触点、装备所在侧和不对称细节必须跨图一致。

## UI 与图标

先做整套 style contract，再做第一个基准项。hover/pressed 从 normal 编辑，叠图轮廓应重合。面板将装饰放在角部，边缘保持均匀，实测 9-slice 拉伸。除明确要求的字标外不让图像模型生成文字；需要文字时优先在引擎中排版。图标用最终显示尺寸（常见 16/24/32 px，而非仅大图）检查剪影、对比和语义。

## 动画与 Sprite sheet

先定义动作相位、锚点、循环边界和 fps。可用视频辅助理解连续运动，但必须逐帧筛选、清理和重新验证身份与像素；不把视频抽帧天然视为合格。检查相邻帧肢体/道具/特效连续、落点和惯性可读、主体不漂移、最后一帧回到第一帧自然。sheet 无分隔线，画布应可被行列数整除。

## Tileset

单 tile 使用均匀随机纹理、无方向光和标志性地标。把真实文件重复拼成 2×2，检查横纵接缝、四象限重复物、色调梯度与棋盘感。transition tile 明确中心、直边、内外角和材质方向；只有无光向、重力、文字或纹样方向时才声明可旋转复用。

## 场景与特效

场景先标出玩法安全区、UI 避让区、可交互层和视差层。特效保持发射原点、相位和透明边缘稳定；分别在深色、浅色与目标场景背景上检查 halo、截边和加色结果。
