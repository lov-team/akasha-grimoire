# Staging 与引擎 QA

## 文件级检查

1. 用文件识别工具确认编码，不信扩展名。
2. 读取实际宽高、颜色模式、bit depth 与 alpha 通道。
3. 检查透明像素边缘 RGB、孤立杂点、白/黑 halo、裁边和非预期投影。
4. 缩放到真实显示尺寸检查剪影、对比、细节和图标可读性。
5. 对成套资产生成 contact sheet，检查画布、锚点、比例、调色板和风格漂移。
6. 对动画播放正序并显式查看最后到第一帧；对 tile 生成真实 2×2 合成。

## 进入仓库前

- 只复制已选定、命名准确的生产文件；保留淘汰稿和中间件在 staging。
- 对照 manifest/合同逐项核对数量、文件名、像素、alpha、帧序和依赖。
- 扫描凭证、临时 URL、缓存、隐藏元数据与原始 provider 响应。

## 引擎验收

1. 使用项目要求的 import 命令重新导入，检查新增 error/warning。
2. 在真实资源加载路径实例化，而非只在图片查看器预览。
3. 检查过滤、mipmap、压缩、色彩空间、atlas region、锚点、9-slice、碰撞或 tile 邻接设置。
4. 在代表性场景和真实缩放下截图；透明资产至少检查深浅背景，UI 检查拉伸状态，动画检查循环，tile 检查重复铺设。
5. 记录实际命令、退出码、截图/产物路径、已知缺陷与未端到端验证项。
