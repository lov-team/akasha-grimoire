# 资产合同

## 通用字段

为每类资产记录：`name`、用途、目标目录、格式、宽高、alpha、色彩空间、锚点、边距、切片/网格、状态或帧序、import 选项与验收场景。文件名使用项目约定；无约定时用小写 snake_case、语义前缀和零填充帧号，避免空格与无意义版本后缀。

## 默认技术约束

| 类型 | 默认合同 |
|---|---|
| Sprite/道具 | 隔离主体、干净轮廓、透明背景、无烘焙场景与无用投影 |
| UI 面板 | 无文字；角饰集中在角部，边缘均匀，先定义 9-slice 安全区 |
| 按钮状态 | normal/hover/pressed 几何完全一致，只改变状态处理 |
| 图标 | 统一画布、留白、笔画、填充与视觉重量；按真实最小显示尺寸验收 |
| Sprite sheet | cell 等宽等高、无分隔线、主体锚点一致、帧序明确 |
| Tile | 边到边绘制、无独特重复地标；声明是否可旋转复用 |
| 特效 | 透明边缘干净，效果原点稳定，避免未授权的加色混合假设 |

不要假定扩展名代表真实编码。交付前读取文件签名、实际像素、颜色模式和 alpha 极值。保留原始高质量源于仓库外 staging，只把合同要求的生产文件纳入仓库。

## 参考图与固定项目

记录参考图哈希或稳定标识、允许借鉴的风格维度、禁止复刻的角色/Logo/纹样/文案。一个批次固定同一项目、生成路径、基准图、调色板和相机词汇；角色或同套 UI 的后续项从基准 edit-chain，避免独立生成造成漂移。
