## 1. 从需求中提取视觉系统

先把长段风格描述压缩成可执行的五层视觉圣经，不要逐句重复形容词：

1. **媒介**：纯二维、硬边赛璐璐、少层阴影、大面积纯色剪影；
2. **色彩**：主色、辅色、明度结构、唯一强调色及其语义；
3. **造型**：人物轮廓、服装块面、关键道具比例和轮廓光；
4. **空间**：场景保留哪些识别锚点，删去哪些写实细节，如何平面化；
5. **运动语法**：图形元素怎样出现、变形、遮罩、匹配和交棒。

把“高级、酷、冲击力强”改写成可见规则，例如：

- 阴影恒定为一至两层硬边纯色，不出现柔和体积光；
- 城市只由管道、窗框、电线、网格和建筑外轮廓构成；
- 画面深度来自平面层的视差、倾斜、翻转和压缩，不来自写实三维摄影；
- 强调色只在特定叙事对象或危险信号出现，其他镜头不得随意借用。

## 2. 建立角色与色彩连续性

角色描述只冻结跨镜头可识别字段：

- 发型外轮廓、身体比例、服装主色和鞋型；
- 标志性道具的长度、握持关系和屏幕方向；
- 皮肤、身体剪影、轮廓光三者的固定色彩关系；
- 目光、表情幅度和气质，不为每镜发明新情绪；
- 对手角色的帽檐、长外套、手套与主角形成的轮廓差异。

建立色彩预算，而不是只列色名：

| 层级 | 用途 | 规则 |
|---|---|---|
| 主色 | 背景、城市块面、时钟或 UI 大图形 | 占据大部分画面，维持统一冷调 |
| 黑白 | 人物剪影、反相、切片和可读焦点 | 用于最大明度对比 |
| 辅色 | 刀光、轮廓光、扫描与路径 | 只强调运动方向 |
| 唯一强调色 | 对手、液体、警报或危险状态 | 稀疏出现；每次出现都承担叙事语义 |

## 3. 用三层合成设计镜头

每个镜头拆成三层，分别写动作，不让装饰图形与角色争夺同一个节拍：

1. **环境层**：平面城市轮廓、线稿、网格、矩形块和有限视差；
2. **角色层**：一个主要身体动作、道具关系、表情或眼神变化；
3. **MG／UI 层**：圆环、刻度、扫描线、网点、几何切片和遮罩。

每个 MG 元素必须有四个字段：`叙事功能 + 触发动作 + 运动行为 + 离场／交棒方式`。例如：

```text
时钟刻度：表达倒计时；由鞋跟落地触发；从接触点径向弹开；收束成下一镜的水平分割线。
```

若元素没有叙事功能或不能交给下一镜，删除它。不要把时钟、月相、蝴蝶、扫描线、网点和 UI 同时堆进每个镜头。

## 4. 建立视觉母题接力

把转场看作同一图形在相邻镜头中的状态变化，不把转场写成独立特效列表：

```text
上一镜出场图形 → 形状／方向／明度匹配 → 下一镜入场图形
```

优先使用：

- 刀刃轨迹 → 斜向遮罩或建筑切面；
- 水平地面线 → 眼睛特写框或 UI 扫描线；
- 时钟圆环 → 月相、瞳孔、瞄准环或构图框；
- 人物黑色剪影 → 黑场遮罩，再由白色反相剪影揭示；
- 城市矩形块 → 海报分栏、游戏 UI 卡片或下一镜窗框。

允许空间倾斜、翻转、压缩和透视变形，但人物身份、动作方向和图形接力至少保留一项连续锚点，让观众读成“有意重组”而不是随机跳变。

## 5. 编排秒级分镜

每个 2–3 秒成片窗口只承担一个主要角色动作和一个主要图形事件。按以下顺序写：

```text
时间窗：起始构图 → 角色动作 → 环境响应 → MG 触发与行为 → 摄影机／平面视差 → 结束构图 → 交给下一镜的图形
```

三秒窗口可使用以下微节拍：

- `0.00–0.60` 秒：建立清楚的身体局部、轮廓或道具锚点；
- `0.60–2.20` 秒：执行唯一主动作，同时让一组 MG 响应；
- `2.20–3.00` 秒：停止新增信息，形成可切出的图形落点并完成转场交棒。

若模型最低生成时长为 4 秒，为每个三秒成片窗口单独生成 4 秒素材，预留头尾稳定区间，再在剪辑中采用中间约 3 秒。不要让模型一次完成多个镜头、精确 UI、复杂反相和全部匹配转场。

## 6. 当前样例的可复用逻辑

当前 0–9 秒样例不是三个互不相干的画面，而是一条连续的“线 → 刃 → 切片 → 环 → 横框”视觉链：

| 成片窗口 | 角色锚点 | 主要图形事件 | 结束交棒 |
|---|---|---|---|
| 0–3 秒 | 长靴与接近身高的大太刀刀尖，暂不展示完整人物 | 脚步触发白色横线、刻度和矩形块径向弹开；刀尖留下青蓝轨迹 | 刀刃轨迹占据画面，成为斜切揭示线 |
| 3–6 秒 | 镜头沿刀身向上，分段揭示人物 | 黑／白／蓝斜切块、短促黑白反相；城市线稿与网格由切片拼合 | 斜切面稳定成侧向运动的舞台边界 |
| 6–9 秒 | 人物侧面持续前行，冷静眼神作为局部信息 | 背景反向平移；巨大时钟圆环展开；黑色斜面切分画面 | 圆环与斜面压缩为横向眼睛特写框 |

这里的关键不是复用具体图标，而是复用四条方法：

1. **延迟完整揭示**：先用鞋、刀尖、眼睛等局部建立角色，再逐步拼出全身；
2. **动作触发图形**：脚步、刀尖和行走分别触发刻度、轨迹、圆环，不让 MG 自行运动；
3. **同形接力**：上一段的线、斜切和圆环成为下一段构图，不使用无来源转场；
4. **信息分层**：人物动作保持简单，把节奏与空间变化交给平面背景和后期 MG。

## 7. 拆分模型生成与后期合成

先定义责任边界：

- **模型生成**：角色外形、单一身体动作、衣摆和头发的克制次级运动、道具姿态、基础平面背景、简单剪影反相；
- **后期合成**：精确刻度、圆环、月相、扫描线、网点、UI 文字、矩形网格、刀刃形遮罩、黑白反相时点和匹配转场；
- **剪辑控制**：成片采用区间、卡点、速度变化、图形接力和强调色出现频率。

生成 Prompt 只保留会影响人物、动作、构图和基础运动的 MG 轮廓。需要精确几何、可读 UI 或逐帧对齐的部分写入后期合成单，不把它们当作模型必须一次完成的合同。

## 8. 生成前审查

- 全片只有一套媒介、色彩、阴影和形状语言；
- 每个角色的轮廓、服装、道具比例与屏幕方向已冻结；
- 每个时间窗只有一个主要角色动作和一个主要图形事件；
- 每个 MG 元素都有触发、行为、功能和交棒；
- 相邻镜头至少共享形状、方向、明度或动作中的一个连续锚点；
- 强调色只在预定语义出现；
- 模型生成与后期合成责任已分开；
- 每个生成镜头都有头尾稳定区间、预计采用区间和可验收的结束构图。
